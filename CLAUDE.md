# CodeLens AI

AI-powered code understanding and analysis tool.

## Phase 1 Objectives
- Build basic project structure with Next.js and Tailwind CSS.
- Implement reusable components and layout.
- Integrate Monaco Editor with support for multiple languages.
- Provide demo data for code and explanations.
- Ensure accessibility and responsiveness.

## Limitations
- This is a frontend prototype. No real backend, AI, or database integration.
- Bash is unavailable; dependencies must be managed via package.json.
- No automated testing or build execution possible within this environment.
